# TeamLog (팀록)

팀 협업 과제 관리 & 회의록 플랫폼

```
팀 + 로그 = 팀록
```

## 기능

- 📋 **회의 감지** — 텔레그램 메시지에서 자동 감지 + 액션 아이템 추출
- ✅ **과제 관리** — 과제 생성, 상태 변경, 담당자 지정, 마감일 설정
- 👥 **협업** — @멘션으로 협업자 등록, 댓글, 알림
- 📅 **캘린더** — 과제 Due date 자동 연동 + 개인 일정 등록
- 🔔 **알림** — D-day 마감 알림, 멘션 알림, 아침 브리핑
- 🔍 **검색/정렬/필터** — 제목/담당자 검색, 컬럼 정렬, 상태/우선순위 필터

## 명령어

| 명령어 | 설명 |
|--------|------|
| `/addtask 제목 @담당자` | 과제 추가 |
| `/mytasks` | 내 과제 목록 |
| `/done T001` | 과제 완료 |
| `/status T001 진행중` | 상태 변경 |
| `/invite @username` | 사용자 초대 (관리자) |
| `/users` | 등록된 사용자 (관리자) |
